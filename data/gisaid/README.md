# GISAID data

This directory contains the following files:
- B.1.221.tsv.gz
- B.11.tsv.gz

These files comprise pre-filtered data (in gzipped .tsv files) collected from GISAID for either B.11 or B.1.221(.3), containing the following columns:
- accession_id - EPI_ISL accession id
- host - Host, either Human or *Neovison vison*, in case of Mink.
- sample_date - Collection date
- name - Sequence name
- seq - Genome sequence

The GISAID accessions are registered under EPI_SET_260428mg and are available to GISAID users with access credentials.

Shu Y, McCauley J. GISAID: Global initiative on sharing all influenza data - from vision to reality. Euro Surveill. 2017 Mar 30;22(13):30494. doi: 10.2807/1560-7917.ES.2017.22.13.30494. PMID: 28382917; PMCID: PMC5388101.

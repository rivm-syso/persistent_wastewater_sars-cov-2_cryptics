# Processed data

This directory contains the following files that are generated by [src/R/Prepare.R](src/R/Prepare.R):

- alias_key.json - A mapping of Pango lineage aliases to lineages or sets of lineages for recombinants. Sourced from the [pango-designation GitHub repository](https://github.com/cov-lineages/pango-designation).
- freyja_data.tsv.gz - The original Freyja lineage estimates
- genome.gff - Genomic coordinates of the SARS-CoV-2 ORFs sourced from the [NextClade data GitHub repository](https://github.com/nextstrain/nextclade_data/raw/refs/heads/master/data/nextstrain/sars-cov-2/wuhan-hu-1/orfs/genome_annotation.gff3).
- selected_samples.txt - A list of high-cryptic-abundance, high-coverage samples used to generate time-scaled phylogenies.
- viral_load_country.tsv.gz - An extraction of the national average viral load in the Netherlands during the study period, sourced from [the RIVM open data](https://data.rivm.nl/covid-19/COVID-19_rioolwaterdata_landelijk.html).
- viral_load_sites.tsv.gz - An extraction of the WWTP-specific average viral load in the Netherlands during the study period, sourced from [the RIVM open data](https://data.rivm.nl/covid-19/COVID-19_rioolwaterdata.html).

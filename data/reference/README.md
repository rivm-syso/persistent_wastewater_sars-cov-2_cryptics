# Reference data

This directory contains the following file that is sourced by [src/R/Prepare.R](src/R/Prepare.R):

- problematic_sites_sarsCov2.vcf - A list of problematic sites to be excluded in the mutation barcodes file, sourced from the [ProblematicSites_SARS-CoV-2 GitHub repository](https://github.com/W-L/ProblematicSites_SARS-CoV2)

As well as:
- reference.fasta - SARS-CoV-2 reference genome: [*Severe acute respiratory syndrome coronavirus 2 isolate Wuhan-Hu-1, complete genome*](https://www.ncbi.nlm.nih.gov/nuccore/MN908947)
- reference.fasta.fai - SARS-CoV-2 reference genome index
